# 💕 Chá de Fraldas da Isabel

Projeto web desenvolvido para celebrar a chegada da Isabel e criar uma experiência especial para os convidados do seu chá de fraldas.

A aplicação foi desenvolvida como um projeto pessoal, combinando uma interface personalizada com funcionalidades de interação e armazenamento de dados.

## ✨ Funcionalidades

* 🎀 Página personalizada para o evento
* 📅 Informações sobre data e horário
* 💌 Espaço para os convidados deixarem recados
* 🗄️ Armazenamento dos recados utilizando Supabase
* 📱 Interface responsiva para diferentes dispositivos
* 🎨 Design personalizado para a identidade visual do evento

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Supabase

## 📚 Objetivo

Além de criar uma experiência especial para o chá de fraldas, o projeto foi desenvolvido como uma oportunidade de praticar desenvolvimento web, integração com banco de dados e manipulação de dados utilizando JavaScript.

## 👶 Sobre o projeto

A Isabel está chegando, e este projeto foi criado para guardar um pouco do carinho e das mensagens deixadas pelas pessoas que fazem parte desse momento.

Feito com muito carinho para celebrar a chegada da Isabel. 💕
